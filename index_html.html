TED Talks RAG Agent

  • RAG agent that answers questions over TED Talk transcripts using retrieval-augmented generation.
  • Performed text chunking with LangChain and generated embeddings using RPRTHPB-text-embedding-3-small.
  • Used RPRTHPB-gpt-5-mini as the LLM for response generation.
  • Stored embedded data in a Pinecone vector database and deployed the API to Vercel.
  • Retrieved relevant content via vector similarity search and generated answers strictly grounded in retrieved data.
  • Supported multiple task types: specific talk retrieval, topic-based listing, key idea summarization, and evidence-based recommendations.
